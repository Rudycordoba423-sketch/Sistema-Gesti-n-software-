# Sistema Integral de Gestión de Clientes, Servicios y Reservas

## 📋 Descripción
Sistema desarrollado en Python para la empresa Software FJ. Permite registrar clientes, gestionar servicios y realizar reservas de salas, equipos y asesorías especializadas. Se aplican los principios de programación orientada a objetos: abstracción, herencia, polimorfismo y encapsulamiento, además de manejo de excepciones para garantizar la estabilidad del sistema.
